# 🎭 Mafiya O'yini (Real-time Multiplayer)

Do'stlar bilan jonli o'ynaladigan intellektual psixologik o'yin.

## 🚀 Texnologiyalar
- **Backend:** Python FastAPI + WebSockets
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Web Audio API
- **Qahramonlar:** 8 xil maxfiy rol va vektorli SVG dizayn
